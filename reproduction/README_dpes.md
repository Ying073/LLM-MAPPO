# M3 (DPES 双模式信息素) 代码 ↔ 论文对照表

> 复现对象：论文 §IV-A (paper.md S030–S034, 算法 1, 公式 13–17)。
>
> M3 在 M1 环境 + M2 MAPPO 基线之上，加了一套**双模式信息素场**，作为每架 UAV 观测的额外输入，引导它们优先搜高价值 / 长时间未访问的区域，同时抑制重复搜已确认区域。

## 一、DPES 是什么（一句话）

> 给 20×20 每个网格维护一个"信息素标量" `dp_i(t)`：**正值吸引 UAV 来搜，负值排斥 UAV 别再来**。信息素的取值按每个网格的"类别"用不同规则更新，从而编码"这块区域值不值得去"。

## 二、核心模块 ↔ 公式

### 1. 网格分类 `_classify()` ↔ **公式 13**

```python
C(g_i) = 
    G_lu    if  t - t_last > D                       # 超时未访问 → 吸引重访
    G_hv    if  t - t_last <= D 且 0.5 < p < p_max   # 中高价值 → 吸引
    G_cs    if  t - t_last <= D 且 p <= p_min 或 p >= p_max  # 状态已确认 → 排斥
    G_other  否则                                     # 其他 → 无信息素
```

- `p` 用**融合后的全局目标概率** `env.gtpm`（公式 10 的输出）
- `t_last` 用 `env.t_last_visit`（环境里 UAV 每次移动到该格时记录）
- `p_min=0.2, p_max=0.8`（`p_max` 复用公式 11 的 `ξ=0.8`）

### 2. 高价值网格吸引素更新 ↔ **公式 14 + 15**

```python
# 公式 14: dp_i(t) = (1-E_s) * { (1-G_s) * [ dp_i(t-1) + d_i^hv(t) + f_i(t) ] }
self.dp[iy, ix] = (1 - e_s) * ((1 - g_s) * (dp + dep + f[iy, ix]))
```

```python
# 公式 15: f_i(t) = Σ_{i'∈N_i} (G_s / |N_i|) * [ dp_{i'}(t-1) + d_{i'}^hv(t) ]
for (nx, ny) in nb:
    acc += g_s / len(nb) * (dp[ny, nx] + dep)
```

- `E_s` 蒸发、`G_s` 扩散：让吸引素随时间衰减 + 向邻域扩散，反映"目标会迁移"
- `d^hv` = 本步 UAV 访问该格时释放的量（表 II：0.1）

### 3. 长时间未访问网格吸引素 ↔ **公式 16**

```python
# 公式 16: dp_i(t) = dp_i(t-1) + d_i^lu(t)
self.dp[iy, ix] = self.dp[iy, ix] + self.d_lu
if (ix, iy) in visited: self.dp[iy, ix] = 0.0   # 访问后立即清零
```

- **不蒸发、不扩散**（与公式 14 的本质区别），访问即清零 → 持续提示"该重访了"
- `d_lu` = 0.003（很小，随时间缓慢累积）

### 4. 已确认状态网格排斥素 ↔ **公式 17**

```python
# 公式 17: dp_i(t) = -(1-E_s) * [ dp_i(t-1) + d_i^cs(t) ]
self.dp[iy, ix] = -(1 - e_s) * (self.dp[iy, ix] + self.d_cs)
```

- **负值** = 排斥；蒸发 `E_s` 但**不扩散**（`G_s=0`，因为确认状态是局部属性）
- `d_cs` = 0.2（表 II），时效过后（重访线程 D 步）自然失效

### 5. 接入 Actor 观测 ↔ **公式 18 + S034**

```python
# env_wrapper._uav_obs(): 把感知域内的信息素 patch 追加到观测
dp_patch = self.dpes.get_patch(self.env, n, half=2)   # (5,5)
return concat([own(3), geum(25), zeta(25), dp_patch(25), obstacle(3), uav_other(3), energy(1)])
```

- **无 DPES** → 观测 60 维（M2 基线）
- **有 DPES** → 观测 85 维 = 60 + 25（信息素 patch），这正是 S034 说 `DP_n(t)` 作为策略输入

## 三、参数（论文表 II）

| 符号 | 含义 | 值 |
|---|---|---|
| `D` | 重访阈值 | 200 步 |
| `E_s` | 蒸发系数 | 0.1 |
| `G_s` | 扩散系数 | 0.1 |
| `d^hv` | 高价值网格释放量 | 0.1 |
| `d^lu` | 长时间未访问释放量 | 0.003 |
| `d^cs` | 已确认状态释放量 | 0.2 |
| `p_min` / `p_max` | 确认状态阈值 | 0.2 / 0.8 |

## 四、一个 episode 里信息素场的变化（验证日志）

随机策略，seed=0，无训练纯采样：

| 时间步 | 吸引(正) | 排斥(负) | max(dp) | 说明 |
|---|---|---|---|---|
| 50 | 0 | 155 | 0.000 | 只有排斥：UAV 在已确认区释放排斥素 |
| 200 | 0 | 298 | 0.003 | 吸引素刚萌芽（`t-t_last > D=200` 才触发 G_lu） |
| 300 | 140 | 252 | 0.303 | 吸引素快速增长：长时间未访问区的重访信号 |
| 400 | 154 | 243 | 0.603 | 双模式成熟：吸引正 + 排斥负并存 |

这个时间演化**完美对应论文**：排斥素"先出现、抑制冗余"，吸引素"随时间累积、引导重访"。

## 五、跑通的标志（A/B 对比）

```bash
# 对照组 (无 DPES, M2 基线)
python train.py --total-episodes 120 --seed 42

# 实验组 (有 DPES, M3)
python train.py --total-episodes 120 --seed 42 --use-dpes
```

**期望差异**（得益于信息素引导）：
1. 同 seed 下，**实验组 searched 更高**（论文里 MDPS-improved vs MDPS）
2. 实验组 area_unc 下降趋势更早、更低
3. reward 收敛更快、更高

> 注意：论文里"加 DPES 后成功率从 0 → 47%"（MDPS vs MDPS-improved 消融），
> 说明 **纯信息素引导本身就能显著提升搜索效率**，这正是我们 A/B 要复现的结论。

## 六、故意简化的地方

| 简化 | 现在 | 升级时 |
|---|---|---|
| 信息素释放判定 | 用 `uav_pos` 判断"被访问" | 可细化：按感知域覆盖格来算，而非仅自身格 |
| 邻居扩散 | 4 邻域 | 可扩展为 8 邻域或带权重 |
| 观测拼接 | 简单 concat 信息素 patch | 可加 attention 让网络自学习信息素权重 |
| 只做 A/B | 未接 LRS | M4 用 LLM 同时优化奖励 + 信息素权重 |
